# CS309 Assignment

Based on the supplied project files.

## Included assignment requirements
- Responsive layout: 2 columns on tablet and 3 columns on desktop.
- Styled form inputs, labels, buttons, and select dropdowns.
- CSS-only modal using `:target`, without JavaScript.
- Alert / notification message styles.
- Dark mode using `@media (prefers-color-scheme: dark)`.
- Accessibility fixes to be verified using Lighthouse in Chrome DevTools.

## Lighthouse
Run Lighthouse on the pages in Chrome DevTools and review/fix any reported accessibility issues. A score above 90 must be verified by running the audit; it is not claimed here.
